NOTAS DEL PROYECTO: MI BIBLIOTECA
================================

Este archivo sirve como bloc de notas para ubicar las carpetas y entender
para qué se usa cada archivo. El inventario refleja los archivos presentes
en el proyecto al momento de crear estas notas.

IMPORTANTE
----------
- Los archivos .env contienen configuracion local y pueden tener contrasenas
  o claves. No compartas su contenido ni lo publiques.
- node_modules contiene dependencias instaladas por npm; se omite porque se
  genera con npm install y puede ocupar mucho espacio.
- web/dist contiene la compilacion generada del frontend. No se suele editar
  manualmente; se vuelve a crear al compilar.

ARCHIVOS DE LA RAIZ
-------------------

  Indica qué archivos o carpetas debe ignorar Git, por ejemplo archivos

  Guia general: requisitos, instalacion, configuracion, endpoints y rutas.

API: api/
---------

La API es el servidor Node.js/Express. Recibe peticiones del frontend, valida
datos, aplica autenticacion y consulta MySQL.

api/.env
  Configuracion local de la API. Puede contener credenciales; no compartir.

api/.env.example
  Plantilla de las variables que hay que configurar en .env.

api/package.json
  Dependencias, metadatos y comandos para ejecutar o probar la API.

api/package-lock.json
  Versiones exactas de dependencias instaladas por npm.

api/src/server.js
  Inicia el servidor y lo pone a escuchar en el puerto configurado.

api/src/app.js
  Configura Express, CORS, rutas y middleware general de errores.

api/src/config/db.js
  Configura la conexion o pool de conexiones hacia MySQL.

api/src/routes/
  Define las URLs y metodos HTTP, y los conecta con sus controladores.

api/src/routes/auth.routes.js
  Rutas de registro e inicio de sesion.

api/src/routes/autores.routes.js
  Rutas para listar, crear y eliminar autores.

api/src/routes/libros.routes.js
  Rutas para operaciones sobre libros personales, incluyendo cambios de
  estado, PDF y datos del libro.

api/src/routes/catalogo.routes.js
  Rutas para buscar y consultar las obras compartidas.

api/src/controllers/
  Recibe las peticiones, valida sus datos y prepara las respuestas HTTP.

api/src/controllers/auth.controller.js
  Implementa registro e inicio de sesion.

api/src/controllers/autores.controller.js
  Coordina las operaciones y respuestas de autores.

api/src/controllers/libros.controller.js
  Coordina las operaciones, validaciones y respuestas de libros.

api/src/models/
  Contiene las consultas a la base de datos.

api/src/models/usuarios.model.js
  Consultas relacionadas con las cuentas de usuario.

api/src/models/autores.model.js
  Consultas para los autores de cada usuario.

api/src/models/libros.model.js
  Consultas para libros, estados, PDFs y catalogo compartido.

api/src/middlewares/
  Funciones que se ejecutan durante el procesamiento de una peticion.

api/src/middlewares/requiereAutenticacion.js
  Verifica el token de autenticacion y asocia el usuario a la peticion.

api/src/middlewares/subirPdf.js
  Procesa y limita la carga de archivos PDF.

api/src/middlewares/errores.js
  Centraliza el manejo de errores de la API.

api/src/utils/
  Utilidades reutilizables para validaciones y procesamiento de PDF.

api/src/utils/validaciones.js
  Reglas de validacion usadas por la API.

api/src/utils/pdf.js
  Funciones auxiliares para procesar documentos PDF.

api/src/utils/pdf.test.js
  Pruebas automatizadas de las utilidades PDF.

database/schema.sql

database/migrations/

FRONTEND: web/
--------------

El frontend React/Vite se ejecuta en el navegador. No se conecta directamente
a MySQL: envia peticiones HTTP a la API.

web/.env
  Configuracion local del frontend, como la URL base de la API.

web/.env.example
  Plantilla de configuracion del frontend.

web/package.json
  Dependencias del frontend y comandos de desarrollo, compilacion y vista
  previa.

web/package-lock.json
  Versiones exactas de dependencias instaladas por npm.

web/vite.config.js
  Configura Vite, el complemento de React y el puerto de desarrollo.

web/index.html
  Documento HTML inicial. Incluye el elemento root donde React monta la app.

web/dist/
  Resultado generado de la compilacion. Los nombres de los archivos pueden
  cambiar en cada compilacion.

web/dist/index.html
  HTML de entrada de la version compilada.

web/dist/assets/
  Recursos generados para produccion.

web/dist/assets/index-CX4LNQQm.js
  JavaScript compilado de la aplicacion en esta compilacion.

web/dist/assets/index-D76Tf_VN.css
  CSS compilado de la aplicacion en esta compilacion.

RECORRIDO GENERAL
-----------------

1. El navegador carga web/index.html.
2. web/src/main.jsx monta React y configura los proveedores.
3. web/src/App.jsx elige la pagina segun la ruta.
4. La pagina usa componentes y hooks para presentar y manejar los datos.
5. Los hooks llaman a los servicios correspondientes.
6. web/src/services/api.js envia la peticion HTTP a la API.
7. La API valida la peticion y consulta MySQL mediante sus modelos.
8. La respuesta vuelve al frontend y React actualiza la pantalla.
